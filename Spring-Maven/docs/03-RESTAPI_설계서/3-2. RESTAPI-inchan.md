

## 1. 담당 API 명세표 (분석 파이프라인)

CodeGuard AI의 핵심 로직이자 비동기 처리가 들어가는 5번~12번 API 목록입니다.

| No | 메서드 | 엔드포인트 | 용도 | 권한 |
| --- | --- | --- | --- | --- |
| 5 | POST | `/api/v1/analyses` | 분석 요청 생성 및 시작 (비동기 트리거) | `USER` |
| 6 | GET | `/api/v1/analyses` | 분석 목록 조회 (페이지네이션) | `USER` |
| 7 | GET | `/api/v1/analyses/{id}` | 분석 상세(요약) 조회 | `USER` |
| 8 | GET | `/api/v1/analyses/{id}/status` | 분석 진행 상태 폴링 (클라이언트 2초 주기) | `USER` |
| 9 | DELETE | `/api/v1/analyses/{id}` | 분석 삭제 (진행 중일 때 차단) | `USER` |
| 10 | GET | `/api/v1/analyses/{id}/files` | 파일 트리 조회 (코드 본문 제외) | `USER` |
| 11 | GET | `/api/v1/analyses/{id}/files/{fileId}` | 파일 코드 본문 조회 (하이라이트 마커 포함) | `USER` |
| 12 | GET | `/api/v1/analyses/{id}/findings` | 취약점 목록 조회 (LLM 요약 포함) | `USER` |

### GlobalExceptionHandler (전역 예외 처리기)

[GlobalControllerAdvice.java](https://github.com/pjt-2team-4/pjt-2team-4/blob/BE/Spring-Maven/src/main/java/com/rookies6/myspringboot4project/exception/GlobalControllerAdvice.java)

```java

@Slf4j
@RestControllerAdvice
public class GlobalExceptionHandler {

    // 비즈니스 로직 상 발생하는 커스텀 예외 처리
    @ExceptionHandler(BusinessException.class)
    public ResponseEntity<ApiResponse<Void>> handleBusinessException(BusinessException e) {
        ErrorCode code = e.getErrorCode();
        return ResponseEntity.status(code.getHttpStatus())
                .body(ApiResponse.error(code, e.getMessage()));
    }

    // @Valid 검증 실패 시 발생하는 예외 처리 (400)
    @ExceptionHandler(MethodArgumentNotValidException.class)
    public ResponseEntity<ApiResponse<Void>> handleValidationException(MethodArgumentNotValidException e) {
        List<ApiResponse.FieldErrorDto> fieldErrors = e.getBindingResult().getFieldErrors().stream()
                .map(fe -> new ApiResponse.FieldErrorDto(fe.getField(), fe.getDefaultMessage()))
                .collect(Collectors.toList());

        return ResponseEntity.badRequest()
                .body(ApiResponse.validationError(fieldErrors));
    }

    // 인가 실패 (소유권 불일치 등 403)
    @ExceptionHandler(AccessDeniedException.class)
    public ResponseEntity<ApiResponse<Void>> handleAccessDeniedException(AccessDeniedException e) {
        return ResponseEntity.status(HttpStatus.FORBIDDEN)
                .body(ApiResponse.error(ErrorCode.ACCESS_DENIED));
    }

    // 그 외 처리되지 않은 모든 서버 에러 (500)
    @ExceptionHandler(Exception.class)
    public ResponseEntity<ApiResponse<Void>> handleUnexpectedException(Exception e) {
        log.error("Unexpected error occurred: ", e); // 로그에는 스택트레이스를 남기고
        return ResponseEntity.internalServerError()
                .body(ApiResponse.error(ErrorCode.INTERNAL_SERVER_ERROR)); // 응답에는 내부 구조 노출 방지
    }
}

```

### ApiResponse (공통 JSON 포맷)

```java

@Getter
@JsonInclude(JsonInclude.Include.NON_NULL)
public class ApiResponse<T> {

    // 공통 필드
    private final boolean success;
    private final String message;
    private final String timestamp;

    // 성공 시 반환되는 데이터 (에러 시 null)
    private final T data;

    // 에러 시 반환되는 필드들 (성공 시 null)
    private final Integer statusCode;
    private final String errorCode;
    private final List<FieldErrorDto> fieldErrors;

    private ApiResponse(boolean success, T data, String message, Integer statusCode, String errorCode, List<FieldErrorDto> fieldErrors) {
        this.success = success;
        this.data = data;
        this.message = message;
        this.timestamp = LocalDateTime.now().format(DateTimeFormatter.ofPattern("yyyy-MM-dd HH:mm:ss"));
        this.statusCode = statusCode;
        this.errorCode = errorCode;
        this.fieldErrors = fieldErrors;
    }

    // 1. 성공 응답 (데이터 + 메시지)
    public static <T> ApiResponse<T> success(T data, String message) {
        return new ApiResponse<>(true, data, message, null, null, null);
    }

    // 2. 성공 응답 (데이터만 반환할 때)
    public static <T> ApiResponse<T> success(T data) {
        return new ApiResponse<>(true, data, "요청이 성공적으로 처리되었습니다", null, null, null);
    }

    // 3. 성공 응답 (반환할 데이터가 없고 메시지만 있을 때, 예: 분석 삭제)
    public static ApiResponse<Void> success(String message) {
        return new ApiResponse<>(true, null, message, null, null, null);
    }

    // 4. 일반 비즈니스 에러 응답
    public static ApiResponse<Void> error(ErrorCode errorCode) {
        return new ApiResponse<>(
                false, 
                null, 
                errorCode.getMessage(),
                errorCode.getHttpStatus().value(), 
                errorCode.name(), 
                null
        );
    }

    // 5. 메시지를 오버라이드해야 하는 에러 응답
    public static ApiResponse<Void> error(ErrorCode errorCode, String message) {
        return new ApiResponse<>(
                false, 
                null, 
                message,
                errorCode.getHttpStatus().value(), 
                errorCode.name(), 
                null
        );
    }

    // 6. 입력값 검증 실패(400) 에러 응답
    public static ApiResponse<Void> validationError(List<FieldErrorDto> fieldErrors) {
        ErrorCode code = ErrorCode.VALIDATION_ERROR;
        return new ApiResponse<>(
                false, 
                null, 
                code.getMessage(),
                code.getHttpStatus().value(), 
                code.name(), 
                fieldErrors
        );
    }

    @Getter
    @AllArgsConstructor
    @NoArgsConstructor(access = AccessLevel.PROTECTED)
    public static class FieldErrorDto {
        private String field;
        private String message;
    }
}
```
