## 1. Entity 설계 개요

### 1.1 설계 목적

> JPA Entity 클래스 설계를 통해 객체-관계 매핑(ORM)을 정의하고,
> 소스 코드 분석 요청, 보안 규칙, 그리고 LLM 분석 결과를 유기적으로 연결하여 유지보수가 용이한 시스템 구축

### 1.2 설계 원칙

* **단일 책임 원칙**: 하나의 Entity는 하나의 비즈니스 개념만 표현
* **캡슐화**: 비즈니스 로직을 Entity 내부에 구현
* **불변성**: 가능한 한 불변 객체로 설계
* **연관관계 최소화**: 필요한 관계만 매핑하여 복잡도 감소

### 1.3 기술 스택

* **ORM 프레임워크**: Spring Data JPA 3.x
* **데이터베이스**: MariaDB 10.11
* **검증 프레임워크**: Bean Validation
* **감사 기능**: Spring Data JPA Auditing

## 3. 공통 설계 규칙

### 3.1 네이밍 규칙

| 구분 | 규칙 | 예시 | 비고 |
| --- | --- | --- | --- |
| **Entity 클래스명** | PascalCase | `User`, `SecurityRule` | 단수형 사용 |
| **테이블명** | snake_case | `users`, `security_rules` | 복수형 사용 |
| **컬럼명** | snake_case | `user_id`, `created_at` | 언더스코어 구분 |
| **연관관계 필드** | camelCase | `analysisRequests`, `securityRule` | 객체 참조명 |
| **boolean 필드** | is + 형용사 | `isActive`, `isResolved` | 명확한 의미 |

### 3.2 ID 생성 전략

| Entity | 전략 | 이유 | 예시 |
| --- | --- | --- | --- |
| **User** | IDENTITY | MariaDB Auto Increment 활용 | 1, 2, 3, ... |
| **SecurityRule** | IDENTITY | 규칙 관리용 순차 증가 | 1, 2, 3, ... |
| **AnalysisRequest** | IDENTITY | 대규모 요청 추적 | 1, 2, 3, ... |

### 4.3 AnalysisRequest Entity

#### 4.3.1 필드 상세 명세

| 필드명 | 데이터 타입 | 컬럼명 | 제약조건 | 설명 | 비즈니스 규칙 |
| --- | --- | --- | --- | --- | --- |
| **id** | `Long` | `analysis_request_id` | PK, NOT NULL, AUTO_INCREMENT | 분석 요청 고유 ID | 시스템 자동 생성 |
| **language** | `String` | `language` | NOT NULL, LENGTH(20) | 입력 코드 언어 | 예: java, python 등 |
| **sourceCode** | `String` | `source_code` | MEDIUMTEXT, NOT NULL | 사용자 입력 소스 코드 | 분석 대상 원본 코드 |
| **status** | `String` | `status` | NOT NULL, LENGTH(20), DEFAULT 'PENDING' | 분석 진행 상태 | PENDING, SUCCESS, FAILED |
| **errorMessage** | `String` | `error_message` | LENGTH(500), NULL 허용 | 실패 사유 | 에러 발생 시 기록 |

#### 4.3.2 연관관계 및 구현 예시

```java
@Entity
@Table(name = "analysis_request")
@NoArgsConstructor(access = AccessLevel.PROTECTED)
@Getter
public class AnalysisRequest extends BaseEntity {

    @Id
    @GeneratedValue(strategy = GenerationType.IDENTITY)
    @Column(name = "analysis_request_id")
    private Long id;

    @ManyToOne(fetch = FetchType.LAZY)
    @JoinColumn(name = "user_id", nullable = false)
    private User user;

    @Column(nullable = false, length = 20)
    private String language;

    @Lob
    @Column(name = "source_code", nullable = false, columnDefinition = "MEDIUMTEXT")
    private String sourceCode;

    @Column(nullable = false, length = 20)
    private String status = "PENDING";

    @Column(name = "error_message", length = 500)
    private String errorMessage;

    @OneToMany(mappedBy = "analysisRequest", cascade = CascadeType.ALL, orphanRemoval = true)
    private List<VulnerabilityFinding> findings = new ArrayList<>();

    // 비즈니스 상태 변경 메서드
    public void updateStatus(String status, String errorMessage) {
        this.status = status;
        this.errorMessage = errorMessage;
    }
}

```

### 4.4 VulnerabilityFinding Entity

#### 4.4.1 필드 상세 명세

| 필드명 | 데이터 타입 | 컬럼명 | 제약조건 | 설명 | 비즈니스 규칙 |
| --- | --- | --- | --- | --- | --- |
| **id** | `Long` | `finding_id` | PK, NOT NULL, AUTO_INCREMENT | 탐지된 취약점 고유 ID | 시스템 자동 생성 |
| **startLine** | `Integer` | `start_line` | NOT NULL | 시작 라인 | 1 이상의 정수 |
| **endLine** | `Integer` | `end_line` | NOT NULL | 종료 라인 | start_line 이상 |
| **codeSnippet** | `String` | `code_snippet` | TEXT, NOT NULL | 문제 코드 조각 (Before) | 탐지된 코드 원본 |
| **severity** | `String` | `severity` | NOT NULL, LENGTH(20) | 취약점 등급 | HIGH, MEDIUM, LOW |
| **aiExplanation** | `String` | `ai_explanation` | TEXT, NOT NULL | LLM 분석 원인 및 설명 | AI가 생성한 가이드 |
| **afterCode** | `String` | `after_code` | TEXT, NULL 허용 | 수정된 코드 제안 (After) | AI가 제안한 개선 코드 |

#### 4.4.2 연관관계 및 구현 예시

```java
@Entity
@Table(name = "finding_vulnerability")
@NoArgsConstructor(access = AccessLevel.PROTECTED)
@Getter
public class VulnerabilityFinding extends BaseEntity {

    @Id
    @GeneratedValue(strategy = GenerationType.IDENTITY)
    @Column(name = "finding_id")
    private Long id;

    @ManyToOne(fetch = FetchType.LAZY)
    @JoinColumn(name = "analysis_request_id", nullable = false)
    private AnalysisRequest analysisRequest;

    @ManyToOne(fetch = FetchType.LAZY)
    @JoinColumn(name = "rule_id", nullable = false)
    private SecurityRule securityRule;

    @Column(name = "start_line", nullable = false)
    private Integer startLine;

    @Column(name = "end_line", nullable = false)
    private Integer endLine;

    @Lob
    @Column(name = "code_snippet", nullable = false, columnDefinition = "TEXT")
    private String codeSnippet;

    @Column(nullable = false, length = 20)
    private String severity; // HIGH, MEDIUM, LOW

    @Lob
    @Column(name = "ai_explanation", nullable = false, columnDefinition = "TEXT")
    private String aiExplanation;

    @Lob
    @Column(name = "after_code", columnDefinition = "TEXT")
    private String afterCode;
}

```
