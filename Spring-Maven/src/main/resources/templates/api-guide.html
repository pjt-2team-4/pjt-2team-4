📖 학생 관리 API

StudentController에서 제공하는 API 설명입니다.

← API 테스트
GET

학생 조회

GET /api/user

전체 학생 조회

데이터베이스에 등록된 모든 학생 정보를 조회합니다.

응답 예시 
{
  "id": 1,
  "name": "홍길동",
  "studentNumber": "AB123"
}
GET /api/user/{id}

ID로 학생 조회

학생의 고유 ID를 이용하여 특정 학생을 조회합니다.

Path Variable id 학생의 데이터베이스 ID
요청 예시 
GET /api/user/1
GET /api/user/number/{studentNumber}

학번으로 학생 조회

학생의 학번을 이용하여 특정 학생을 조회합니다.

Path Variable studentNumber 학생 학번
요청 예시 
GET /api/user/number/AB123
POST

학생 등록

POST /api/user

새로운 학생 등록

새로운 학생 정보를 데이터베이스에 등록합니다.

필수 정보 이름, 학번
요청 예시 
{
  "name": "홍길동",
  "studentNumber": "AB123",
  "detailRequest": {
    "address": "서울시",
    "phoneNumber": "010-1234-5678",
    "email": "test@test.com",
    "dateOfBirth": "2000-01-01"
  }
}
PUT

학생 수정

PUT /api/user/{id}

학생 정보 수정

기존 학생의 이름, 학번 및 상세 정보를 수정합니다.

Path Variable id 수정할 학생의 ID
DELETE

학생 삭제

DELETE /api/user/{id}

학생 삭제

학생 ID를 이용하여 학생 정보를 삭제합니다.

Path Variable id 삭제할 학생의 ID
⚠️ 삭제된 학생 정보는 복구할 수 없습니다.
